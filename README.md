# A note for Shade

A calm, mobile-friendly apology and dinner invitation built with vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with a local static server.

## Build

```sh
npm run build
```

The build copies the static site into `dist/`.

## Deploy on Render

Create a Static Site for this repository with build command `npm run build` and publish directory `dist`.

Edit the message copy in `slides.js`.
